# BRIANS Lab Website

This site was merged from Brian Staes' existing static HTML website into a Jekyll academic template structure.

## Deploying on GitHub Pages

1. Upload the contents of this folder to your GitHub Pages repository.
2. In GitHub, go to **Settings → Pages**.
3. Set the source to the main branch/root folder.
4. GitHub Pages will build the Jekyll site automatically.

## Notes

- Main navigation is controlled in `_config.yml` under `links:`.
- Site owner/sidebar information is controlled in `_config.yml` under `owner:`.
- Custom BRIANS Lab styling was appended at the end of `assets/css/main.css`.
- Original template license is preserved in `LICENSE-template-MIT.txt`.
